# 🛒 Shopping Wishlist Manager

A simple Java-based console application to manage your shopping wishlist using **Singly Linked List** and **File Handling**.

## ✨ Features
- Add shopping items with automatic IDs.
- Display all wishlist items.
- Sort items by price.
- Remove items using their IDs.
- Calculate total wishlist cost.
- Save and load data using `wishlist.txt`.

## 🛠️ Technologies Used
- Java (JDK 21)
- Singly Linked List
- File Handling
- Data Structures and Algorithms

## ▶️ How to Run
```bash
javac ShoppingWishlistManager.java
java ShoppingWishlistManager
```
